# Historical compatibility: Omarchy 4.0.6

This records the original review of [v4.0.6 at `237f1b4`](https://github.com/omacom/omarchy/tree/237f1b4071a0bff2296c6d740ba2b9fd695ebfa0), including v4.0.5, against v4.0.4. Cleaner 3.3 later passed live tests on both 4.0.6 and 4.5.0; see the [current validation report](v4.5.0-compatibility.md).

## Release changes

The 4.0.x tags came from a release branch descending from v4.0.0. The earlier [Quattro comparison](quattro-catalogue-10f1cbf.md) describes a different branch.

| Area | Finding |
| --- | --- |
| Packages | Base packages and the removable package list match 4.0.4. |
| CLI wrappers | The 15 mise installer tuples and wrapper generator match 4.0.4. Hermes is no longer provisioned. |
| Launchers | The 13 webapp/TUI launchers are unchanged. The new `omarchy-browser.desktop` is a native link handler, excluded by the webapp command check and retained as a negative fixture. |
| Bindings | `applications.lua` is byte-identical to 4.0.4. |

## Hermes ownership

In 4.0.5, Hermes moved to a self-updating desktop checkout. Its helper replaced `--owns` with `--check`, `--now`, and `--retire-mise`. The unsupported ownership query exits before changing anything.

Cleaner preserves those wrappers: deleting one before migration could orphan its mise environment. The older `--owns` contract remains supported for 4.0.3–4.0.4. Optional Hermes Desktop and OpenClaw installations are outside the default catalogue.

## Validation at the time

Syntax, ShellCheck 0.11.0, and 48 regression tests passed. The catalogue extractor reproduced existing snapshots; tests covered the new native desktop. Read-only checks on 4.0.6-1 verified wrapper ownership, symlink preservation, existing unbinds, and the harmless rejection of Hermes' `--owns` query.

No live VM removal was performed in this original review. Later live validation appears in the current report linked above. The 4.5 release candidate was deferred then; Cleaner 3.3 now handles final 4.5.0's packages, command-string bindings, and grouped lazy-tool opt-out.
